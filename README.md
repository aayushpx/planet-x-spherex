# Planet-X SPHEREx

## Architecture

- `api/` - Python backend and SPHEREx data retrieval.
- `science/` - Scientific image processing and analysis.
- `web/` - Frontend application and Three.js visualisation.
- `data/samples/` - Small sample datasets for development and demonstrations.
- `tests/` - Automated tests.
- `docs/` - Architecture and API documentation.

## Development

The frontend, backend and scientific processing modules are developed
independently and integrated through the API contract.
